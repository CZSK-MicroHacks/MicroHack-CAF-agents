# knowledge-agent

Leverages Foundry IQ in Foundry Agent Service to process rich wine knowledge from descriptions, audio, PDFs, and selected public wine websites.

During this challenge, participants will:
- Use an Azure environment with Microsoft Foundry, Foundry IQ, Blob Storage, AI Search, and related services.
- Create an indexer by importing `wines.json` to build an index ready for keyword and semantic search.
- Add Semantic Configuration and validate that search works end to end.
- Create a knowledge base in Foundry and link the index to it.
- Add audio file processing.
- Add rich PDF processing for text, tables, images, and charts.
- Add web search using selected wine-focused websites.
- Combine all sources into one knowledge base and create a Foundry Agent that uses it.
- Import evaluations and verify the agent passes functional and red-teaming tests.
