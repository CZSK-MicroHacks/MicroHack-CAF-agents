# MicroHack-CAF-agents

MicroHack for AI agents, run as part of the Cloud Architecture Forum 2026 event.

The business-data-agent challenge focuses on using Fabric IQ to process wine business data, the knowledge-agent challenge focuses on building a Foundry IQ knowledge base from multimodal wine sources, and the user-agent challenge focuses on delivering a warm Copilot Studio experience grounded in both backend agents for Microsoft 365 Copilot and Teams users.
